# TabBar 图标说明

需要准备以下图标文件（建议尺寸：81x81px）：

## 首页图标
- `home.png` - 首页图标（未选中状态）
- `home-active.png` - 首页图标（选中状态，蓝色）

## 灵感图标
- `inspiration.png` - 灵感图标（未选中状态）
- `inspiration-active.png` - 灵感图标（选中状态，蓝色）

## 我的图标
- `profile.png` - 我的图标（未选中状态）
- `profile-active.png` - 我的图标（选中状态，蓝色）

## 图标颜色
- 未选中：#94A3B8（灰色）
- 选中：#2E58EB（品牌蓝）

可以使用以下工具生成图标：
- IconFont: https://www.iconfont.cn/
- IconScout: https://iconscout.com/
- Figma: 自行设计
